# 赛博玉玺 · 数字御制工坊

一款在浏览器中创作诏书与印章的本地工作台。Vue 3 + TypeScript + Canvas 2D，无 UI 库、图片或音频素材；宣纸纹理、印面磨损与落印音效均实时生成。

## 运行

需要 Node.js 22+、pnpm 12。

```bash
pnpm install
pnpm dev       # http://localhost:5273
pnpm build     # 类型检查 + 生产构建
pnpm test      # 竖排、历史记录与草稿恢复回归测试
pnpm preview
```

## 创作流程

1. 选择敕封圣旨、上线大吉、准予休沐或自由创作。填写受封者后选择模板，会将名字写入正文；也可随机拟旨或自行编辑，正文最多 1200 个 UTF-16 单元。
2. 选择古宣、素笺或玄金纸张，自定义 1–8 字印文。印文按右起竖读排列，留空使用传国玉玺八字。
3. 调整印色、力度、磨损与尺寸。点击纸面、拖动印盒中的玉玺，或使用「落款用印」。新的设置只影响之后的印痕。
4. 导出 2×（2400 × 1600）或 4×（4800 × 3200）PNG。导出始终包含完整正文，不含光标预览或工作台控件。

正文与印痕自动保存在当前浏览器的 localStorage，刷新后恢复。存储不可用时仍能创作，请及时导出。切换模板保留印痕；「清空印痕」可撤销。每份作品最多 500 枚印痕，撤销历史保留 50 次操作，刷新后历史重置。

桌面使用三栏工作台，圣旨独占中央展示区，按可用宽高完整放大并居中。平板将编辑器放到下方，手机按画布、玉玺、正文依次排列。专注模式隐藏侧栏，`Esc` 退出。

预览工具栏可「收起圣旨」与「展开圣旨」，纸面从中间向两侧展读，卷轴随边缘移动；收起后也可点击卷轴上的「御制圣旨」展开。收起和动画期间暂停点击、拖拽及落款盖印，正文与印痕保留；PNG 导出始终为完整作品。收起状态仅用于当前会话预览，刷新后展开；「重放书写」会先展开圣旨。系统设置为减少动态效果时直接切换状态。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl / ⌘ Z | 撤销印痕操作 |
| Ctrl / ⌘ Shift Z 或 Ctrl / ⌘ Y | 重做 |
| Ctrl / ⌘ S | 导出作品 |
| Ctrl / ⌘ Enter 或 Alt Enter | 随机拟旨 |

编辑框内的撤销／重做交给浏览器，不会误撤销印痕。

## 结构

- `src/App.vue`：共享状态、页面导航与跨页面拟旨。
- `src/layouts/AppLayout.vue`：公共导航、主题切换、帮助弹窗和状态页脚，通过插槽承载页面与操作。
- `src/pages/StudioPage.vue`：工坊编辑、玉玺设置、圣旨展示、盖印与导出交互。
- `src/pages/EmperorPage.vue`：皇帝身份、宫册与翻牌。
- `src/pages/TreasuryPage.vue`、`OfficialsPage.vue`、`PalaceMapPage.vue`：双库、文武官制与宫殿地图。
- `src/pages/MemorialPage.vue`、`src/core/memorial.ts`：奏折簿、上奏与朱批、状态流转和批阅留档。
- `src/core/empire.ts`：库藏规则、十九档品级、宫殿布局及领域数据恢复。
- `src/composables/useStudio.ts`：草稿数据、校验、自动保存、印痕历史及模板。
- `src/components/ImperialCanvas.vue`：固定 1200 × 800 文档、视口坐标转换、预览与独立导出。
- `src/components/FloatingSeal.vue`：指针拖拽、命中检测、归位与取消处理。
- `src/core/stamp.ts`：可序列化印痕；纹理与动画时钟不进入持久化数据。
- `src/core/seal.ts`：自定义字格、确定性磨损与有界纹理缓存。
- `src/core/paper.ts`：三款纸张、颗粒及卷轴边框。
- `src/core/text.ts`：中文竖排、旋转括号、行末悬挂标点。
- `tests/`：Node 内置测试工具，使用已有 TypeScript 编译器加载源码，无额外测试依赖。

文档坐标与显示尺寸独立，改变窗口大小不会移动印痕。绘制按需触发，静止预览不持续占用动画帧。纸张纹理只生成一次，印面缓存限制为 48 张，避免滑杆交互长期累积位图。

`Ma Shan Zheng` 与 `Noto Serif SC` 为 Google Fonts 可选增强。不可用时使用系统楷体／宋体。导出前等待当前正文与印文的字体子集加载；字形就绪后自动刷新预览。正文和草稿不上传服务器；浏览器会发出字体资源请求。

## 3.0 · 赛博皇帝

顶部导航支持御制工坊与赛博皇帝两个页面，分别使用 `#studio` 和 `#emperor`；直接链接与浏览器前进／后退均可使用。

皇帝页面支持设置国号、皇帝名讳，管理最多 24 位宫册人物（姓名、位份、宫苑、参与状态），随机翻牌、避免连续重复与查看最近 50 次翻牌。只有一位可选人物时允许连续翻中；全部停用时无法翻牌。抽取采用 Web Crypto 拒绝采样。人物移出后可在当前页面恢复，历史记录保留抽签当时的姓名。点击翻牌结果或历史记录的「拟旨」，可直接进入工坊创作带国号和名讳的圣旨。改动身份设置不重写已经编辑的正文，新拟圣旨与卷轴落款使用当前身份。

深色／浅色界面一键切换，与纸张材质独立。主题、王朝设置、宫册、历史、字体和印章角度均随草稿保存；2.0 草稿自动迁移，旧印痕保留宋体与原角度。

玉玺支持 -180°～180° 精确旋转，提供 -45°、0°、45°、90° 快捷角度。印盒、光标预览、真实盖印与 PNG 导出使用同一个角度，旋转后的边界也会约束在纸面内。每枚印痕独立记录字体与角度，新设置不改动已有印痕。

圣旨与玉玺可分别选择毛笔行楷、楷体、宋体、黑体、隶书，或导入本地 TTF／OTF／WOFF／WOFF2。默认玉玺为项目原创的「受命于天既寿永昌」八字鸟虫篆风格矢量印面，**不是完整的历史鸟虫篆字体库**；其他字使用宋体补字，界面会提示，可以切换到其他字体或导入自己的字库。系统书体未安装时按配置回落到可用字体。

本地导入最多 8 款字体，每款不超过 30 MB，保存在 IndexedDB 中，不上传服务器，刷新后会重新载入；存储不可用时会提示仅当前会话有效。字体文件需要含所用汉字，不支持的字形交给后备字体。内置鸟虫篆风格八字采用 Canvas Path2D 渲染，不依赖远程字体。

## 4.0 · 库藏、朝堂与宫城

公共导航增加 `#treasury`（国库与皇室宝库）、`#officials`（文武百官）和 `#palace`（宫殿地图），均支持直接链接与浏览器前进／后退。

两库在同一页面展示，至宝自动归入皇室宝库；金银、粮秣、军备、器物、贡品归入国库。支持搜索、分类、收录、编目、入库、出库和当前页移出后恢复。两库共可收录 200 种藏品，每种数量为 0～10 亿整数，出库不得超过库存。类别或单位变化会登记原库存转出和新库存转入，出入库簿保存最近 50 笔收支快照。

官制从正一品、从一品依次排至正九品、从九品，再设不入流，共十九档。正品高于同品从品，文武共用品级顺序，各有不同的默认职名，可修改十八个入流品级的文武职名；不入流固定为「不入流小官」。默认职名是一套可自定义的赛博官制。官册支持 200 人，按文武、品级、姓名与职掌筛选，并可将任命旨送入工坊。

宫殿图沿中轴组织十七处命名建筑与御苑，分为外朝、内廷、宫务、苑囿。地图建筑与名录均可点击、键盘选择；支持保存殿名与用途，并从对应建筑前往库藏、百官或皇帝页面。地图为宫城示意布局。

资料随本机草稿保存，2.0／3.0 草稿迁移至 4.0 后保留原有圣旨、印痕与宫册。新领域按区块校验，损坏的库藏或官册单独恢复默认数据。

## 5.0 · 奏折与批阅

新增 `#memorials`（奏折批阅）页面，宫城地图的勤政殿与乾清宫也可直接进入批阅。奏折簿支持最多 200 份奏折，按草稿、待批、准奏、驳回、发回修改和类别筛选，可搜索题名、具折人、正文与朱批；急奏优先展示，同级按最近更新时间排列。

具折人可从文武官册选取，也可手填，姓名与职名随奏折独立留档，后续官册改动不重写既有奏折。提供赈济灾民、边防修缮与荐贤任官题笺；题名最多 24 字、具折人最多 12 字、正文最多 1200 个 UTF-16 单元。可保存草稿或直接上奏，草稿移出后可在当前页面恢复。

上奏后正文锁定。御前填写最多 400 个 UTF-16 单元的朱批，可准奏、驳回或发回修改；空白批复不能登记。发回的奏折可修订再奏，上奏轮次递增，保留最近 20 次批阅的结果、朱批、批阅人和时间。准奏与驳回的奏折保留原文，不再修改。

已批奏折可将本次批复送入御制工坊，自动带入具折人、奏折题名、前 240 字正文摘录和朱批，供盖印与 PNG 导出。长正文以省略号提示摘录；原有工坊印痕保留。朱批用于记录与拟旨，涉及库藏调拨或官员任命时，需前往相应页面办理。

奏折与朱批随本机草稿保存，2.0／3.0／4.0 草稿自动迁移至 5.0，既有圣旨、印痕、宫册、双库、百官与宫殿数据保留。奏折数据单独校验，损坏时恢复空奏折簿，不影响其他领域。
